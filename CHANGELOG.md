# Changelog

Notable changes will be recorded here. Entries describe user-visible changes; the Git history contains implementation details. The project has no tagged release documented here yet.

## Unreleased

### Added

- Local project management, JSON backup and restore, and imperial or metric measurements.
- Linear and sheet cut planning, mixed-material projects, stock and price settings, diagrams, shopping lists, costs, offcuts, CSV export, and browser print / Save as PDF.
- A project-based 3D Design workspace with modeling tools, reusable components, and reviewed updates to Cutlist. **Design is beta:** bugs, limitations, and further improvements are expected.
- Light, dark, and system themes and responsive project and cutlist layouts.

### Known limitations

- Projects are stored in the browser on the current device; accounts and cloud sync are not available.
- The standalone Design preview does not create or save a project. The 3D workspace has bounded modeling capabilities and incomplete release verification. See the [workspace guide](docs/plankplan-studio-3d-workspace-guide.md).
